Short answer: rarely worth it. Long answer below.

The short answer: Short answer: rarely worth it. Long answer below.

What's reusable

The control box (basically). The app pairing. Maybe the LED strip if it's in good condition and the new house's geometry happens to match.

What's not reusable: the aluminum track. It's cut to fit the previous house's roofline and won't match the new one.

Realistic cost

Removal from old house: ~$400. New install on new house with old hardware where possible: ~$1,800. Total: ~$2,200.

New install from scratch: $2,800. Difference: $600. Most clients pick new install — fewer compromises, full warranty resets.

When it's worth it

You just installed within the last 12 months and the new house is structurally similar. Otherwise, sell the old install with the house and start fresh.
